For a new graph-distance embedding, start with SGD metric MDS and use sparse mode when full fitting is too costly. The weighted-GRIP and edge-KK examples here document alternatives or saved comparisons; they are not an automatic large-graph pipeline.

Installed figures use static projections. To enable 3D rotation and layout selection, render with options(grip.vignette.interactive = TRUE) and ivue and rgl installed.

This companion contains the other nine graphs from the same saved gallery. See the main gallery for the method, errors, alignment, conversion rules, and complete reproduction recipe. All vertices and edges remain in every display; the examples are split across pages to reduce the number of simultaneous 3D views.

A saddle

A grid lifted to a saddle, with horizontal, vertical, and diagonal edges. Traversal lengths are measured between neighboring surface points. Both layouts are Procrustes-aligned to the gray generating surface. The remaining difference in shape cannot be removed by rotating, reflecting, or translating the layouts while keeping corresponding vertices matched.

100 vertices; 342 edges. Supplied edge lengths.

g <- mesh.surface.graph(10, 10, surface = 'saddle', connectivity = 'diagonal', normalize = 'none')

Construction examples

These examples retain the distinctive irregular and recursive families from the former website gallery. They compare generating coordinates with weighted GRIP, separately from the saved metric-MDS/edge-KK collection above. These new teaching fits use the stated seed and the current package; they do not extend the saved MDS timing experiment. For these two teaching views only, each fit is translated, rotated/reflected, and uniformly resized to match the generating reference’s root-mean-square radius. The caption reports the display multipliers.

A folded irregular annulus

annulus <- irregular.annulus.surface.graph(rings=5,outer.count=36,
  inner.radius=.42,surface='folded',amplitude=.2)
annulus.fit <- grip(edges=annulus$edges,n=annulus$n,edge.weights=annulus$edge_weights,
  dim=3,metric='edge_length',preset='irregular',seed=4)

Folded annulus: gray generating reference and weighted GRIP. Aligned at a common overall size for display. Display multipliers: Weighted GRIP 0.00728 . Scores use original coordinates.

The inner boundary forces routes around the hole. The gray generating surface helps explain the graph construction; it is not an exact Euclidean realization of every graph distance.

A recursive cross pattern

cross <- vicsek.surface.graph(level=3,surface='ripple',amplitude=.55)
cross.fit <- grip(edges=cross$edges,n=cross$n,edge.weights=cross$edge_weights,
  dim=3,metric='edge_length',preset='carpet',seed=3)

Recursive Vicsek pattern on a rippled surface. Aligned at a common overall size for display. Display multipliers: Weighted GRIP 0.00218 . Scores use original coordinates.

Recursion introduces repeated branches and bottlenecks. For the recorded stages of a related planar recursive construction, see Tracing and diagnosing layouts.
