Installed figures use static projections. To enable 3D rotation and layout selection, render with options(grip.vignette.interactive = TRUE) and ivue and rgl installed.

This graph summarizes similarities among HMP+U01 16S amplicon samples. The supplied object records a representation based on taxa at at least 1% relative abundance followed by principal component analysis, and a nearest-neighbor construction with k=3. Coarsening reduces the original giant component to 1,828 vertices and 4,656 weighted edges.

The biological labels are community state types (CSTs) and finer subtypes. Use them to interpret groups in the drawing; separated colors do not by themselves establish that the geometry is accurate.

Compare three layouts

The panels show SGD metric MDS, weighted GRIP (metric="edge_length") and hop-based GRIP. The SGD and weighted-GRIP fits use the same coarsened graph, positive edge lengths, three dimensions and seed 1. SGD uses full weighted graph distances, uniform pair weights, a random start and a 200-iteration budget, without edge-KK refinement. Weighted GRIP uses its edge-length hierarchy and default optimization settings. This is a one-seed illustration, not a controlled method-ranking experiment.

Hop-based GRIP uses supplied edge lengths for adjacent attractions and hop distances for hierarchy searches. The figure shows its default preset with seed 1. The preset comparison below also includes tree and torus settings.

HMP/U01: CST colors are identical across layouts. Display only: each layout is centered and scaled to unit RMS radius; saved fits and scores are unchanged.

Rotation helps distinguish actual branches from overlaps in projection. Coordinates are centered and uniformly rescaled to the same root-mean-square radius for display, so each method is visible despite its different fitted scale. Shapes and orientations are preserved, with common bounds and an unchanged camera when switching. CST colors remain fixed. Saved coordinates and diagnostics are unchanged; this display does not compare absolute scale or align layouts to a biological reference.

Reproduce the weighted fits

Start with SGD metric MDS for a new weighted graph-distance fit. The edge-length GRIP alternative used in the figure is shown below. This recipe uses edge-length distances; the preset tables above use hop-based GRIP.

mds <- metric.mds(adj.list=g$adj_list,weight.list=g$weight_list,
  n=length(g$adj_list),dim=3,backend='sgd',init='random',seed=1,
  max.iter=200,pair.weights='uniform',diagnostics=FALSE)
coords <- grip(adj.list=g$adj_list,weight.list=g$weight_list,
  n=length(g$adj_list),dim=3,metric='edge_length',seed=1)
score.layout(coords,adj.list=g$adj_list,weight.list=g$weight_list,
  n=length(g$adj_list),clusters=g$vertex_data$cst,edge.crossings='never')

See weighted layouts for the metric semantics and Choosing and evaluating for repeated seeds and candidate selection.

Data and coarsening record

Saved results reside in extdata/hmp_u01_gc_coarse/vignette_results.rds in the installed package. They include candidate settings, scores, fitted coordinates, and the software session. To run the hop-based preset comparison into a separate file, explicitly set the output path before sourcing its script:

Sys.setenv(GRIP_HMP_RESULTS_OUTPUT='fresh-hmp-results.rds')
source(system.file('scripts','precompute-hmp-results.R',package='grip'))

That script reproduces its documented hop-based workflow; it does not rerun the weighted recipe above. Use separate output files for each comparison.

The SGD and weighted-GRIP fits are stored in weighted_layouts.rds, with settings, warnings, runtimes, source/data checksums and session information. Reproduce them from the source checkout with Rscript inst/scripts/precompute-hmp-layout-selector.R. This does not overwrite the hop-based preset comparison.
