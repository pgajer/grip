# Geodesic MDS Design Notes

This directory is the canonical home for exploratory geodesic-MDS source notes.

Current convention:

- report source bundles live under `dev/design/geodesic_mds/reports/<report>/`
- each report bundle may contain the hand-authored `*.tex` source plus any companion figure directories needed to rebuild that note
- rendered PDFs, LaTeX sidecars, and other generated report artifacts belong under `output/reports/geodesic_mds_paper/`
- smoke image grids and other generated diagnostics also belong under `output/reports/geodesic_mds_paper/`, not under `dev/design/`

This replaces the old flat `dev/design/pdf/` pattern for geodesic-MDS report files.
