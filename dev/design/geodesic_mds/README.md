# Geodesic MDS Design Notes

This directory is the canonical home for exploratory geodesic-MDS source notes.

Current convention:

- benchmark and report generators live under `tools/benchmarks/geodesic_mds_paper/`
  and `tools/reports/geodesic_mds_paper/`
- generated report sources, figures, PDFs, and sidecars belong under
  `output/geodesic_mds_paper/reports/`
- interactive output belongs under `output/geodesic_mds_paper/html/`
- intermediate data belongs under `output/geodesic_mds_paper/tmp/`
- no generated artifacts belong under `dev/`

This replaces both the old flat `dev/design/pdf/` pattern and the later
generated report bundles formerly stored in this source tree.
