# Manuscript Archive

This directory holds named manuscript source snapshots preserved during
migration to the canonical in-repo paper workspace.

Policy:

- `manuscript/geodesic_mds.tex` is the only active manuscript source
- files in this archive are retained as historical checkpoints
- Git history in the `grip` repository remains the primary version history
- `geodesic_mds_v1.tex` through `geodesic_mds_v5.tex` are numbered draft snapshots
- `geodesic_mds_legacy_unversioned_2026-04-02.tex` is the last unversioned
  legacy manuscript copied from the pre-migration workspace
- `geodesic_mds_legacy_unversioned_2026-04-02.pdf` is the matching rendered
  PDF kept as a historical reference copy
