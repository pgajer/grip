# Development archives

This directory preserves historical implementation material that is not part
of the current R package. `legacy-cpp/` contains the pre-package C++ source
archive formerly stored at the repository root.

The unused OpenGL trackball implementation and header were removed in September
2026. Historical viewer sources and makefiles still describe that former
dependency; this archive is a source reference, not a supported build target.
The current R package does not use the archived viewer.
