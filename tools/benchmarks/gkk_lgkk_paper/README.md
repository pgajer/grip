# GKK LGKK Benchmark Scripts

This directory contains benchmark, tuning, and investigation scripts that support the `gkk_lgkk_paper` track and its weighted-GRIP scaling section.

Typical contents:

- `benchmark-*.R` benchmark drivers
- `investigate-*.R` focused diagnostics
- `tune-*.R` parameter studies
- helper benchmark scripts reused across the GKK/LGKK experiment line
